# EMDADAT ALATTA - دليل التحويلات (Ultra Minimal)

هذا المشروع هو دليل تحويلات داخلية مبسط جداً لشركة امدادات العطاء.

## الحالة الحالية للمشروع
تم الانتهاء من تحويل الواجهة إلى نمط **Ultra Minimal** وتجهيز المشروع للنشر التلقائي:
- [x] إزالة جميع المكونات الإضافية (الرسوم البيانية، الإحصائيات، الأزرار العائمة).
- [x] تبسيط بطاقة التحويلة لتظهر الاسم ورقم التحويلة فقط بخط كبير.
- [x] إنشاء هيكلية الخدمات `services` لفصل منطق البيانات عن الواجهة.
- [x] تهيئة المجلدات لإضافة لوحة تحكم `admin` مستقبلاً.
- [x] إصلاح أخطاء البناء (Build) وضمان توافق TypeScript.
- [x] إعداد GitHub Actions للنشر التلقائي.

## ملاحظة هامة للنشر (GitHub Pages)
لقد قمت بإصلاح جميع أخطاء الكود وبناء المشروع بنجاح. ومع ذلك، فشلت خطوة النشر التلقائي (Deploy) بسبب قيود في إعدادات المستودع الخاص بك (Environment Protection Rules).

**لتفعيل النشر، يرجى القيام بالآتي:**
1. اذهب إلى إعدادات المستودع: `Settings` -> `Environments`.
2. إذا وجدت بيئة باسم `github-pages` وبها قيود على الفروع (Deployment branches)، قم بتعديلها لتسمح لفرع `main` بالنشر، أو احذف القيود.
3. بدلاً من ذلك، اذهب إلى `Settings` -> `Pages` وتأكد من اختيار `GitHub Actions` كمصدر للنشر.
